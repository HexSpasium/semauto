# SEM AUTO — Premium Araç Galerisi

SEM AUTO için mobil uyumlu ikinci el otomobil vitrin sitesi.

## Özellikler
- Marka, model, yakıt, vites, kasa tipi ve fiyat filtreleri
- Araç kartları ve detay penceresi
- Kilometre, model yılı, fiyat ve boya/değişen bilgileri
- Örnek araç verileri (gerçek ilan değildir)

## Yayınlama
GitHub Pages ayarlarından `main` dalı ve `/ (root)` klasörünü seçin.

## Yönetim ve veritabanı
Bu ilk sürüm vitrin prototipidir. Yönetici girişi, ilan ekleme/düzenleme, görsel yükleme ve kalıcı veritabanı bağlantısı sonraki aşamada Supabase ile kurulacaktır.
